# 流星淡入淡出增量方案
输入 revision：codex_20261001061311_15c502680e93。
仅改项目层 `src/nodes/star-sea/meteors.ts`（生命周期数学与完整尾迹可见范围）及 `painter.ts`（统一透明度及只读遥测），直接依赖现有 model/View 与公开 createShapeBatch/update。不新增 Runtime 能力或模块；现有流星没有年龄透明度包络，通用库不承载梦境视觉策略。
以出生时固定 depth/screen speed 推导 0.4–0.9s 渐入、0.7–1.4s 渐出；短寿命分别最多占25%/35%，中段保留平台。两端 smoothstep，乘到头芯、尾部全部段及外晕，不改变尺寸或物理轨迹。尾迹全部包围盒（包括光晕）离开视区才回收，淡出仍计入3条硬上限。真实接触立即消耗并起爆，不延时/二次爆炸。
保持随机数序列、seed/reset、超新星、HUD及品牌原样。更新合同中生命周期断言。官方编译后测端点/短寿命/连续性、尾晕边界、预算与碰撞回放回归；有界正式GLSL Preview记录普通流星初生/中段/末段及真实接触/Replay，证据落盘本工程。晋升修订和六门禁不得由本地推定。
