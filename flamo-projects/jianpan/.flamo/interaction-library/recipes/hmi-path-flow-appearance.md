# Runtime pipe visibility — 2.4.0

Use the [range controls](hmi-path-flow-range.md) with the same host methods. New Figma pipes carry `appearanceMode: runtime`; imported PipeSpec visibility becomes managed initial state. Design layers stay selectable. Mounted instance wall/medium/optional hollow outline receive visibility once, even with flow disabled; disposal restores the design projection. Opacity remains authored. Regenerate legacy pipes in the plugin to opt in. Do not edit managed snapshots.

Verify both flags independently, hollow walls, disabled flow, peer isolation, disposal before/after mount and failed initialization. This does not provide a new public appearance setter.
