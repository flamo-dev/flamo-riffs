# 同帧 HUD 与流星入口增量方案

保留现有绘制与交互，仅更换帧调度、入口几何和尺寸速度策略。

- `src/nodes/star-sea/script.ts`：项目组件编排层，依赖公开 NodeScriptContext。用 Runtime `ctx.onUpdate` 唯一驱动时钟、viewport、绘制、遥测；保留 performance.now 差值及 0.1 秒上限以保持软件环境和 Replay 节奏。
- 当前 Runtime SHA256 为用户指定 4234e91a24b5762b7c697c1227352bc61fbb501003ac8a16398569d153e017d7。API manifest 已声明 onUpdate，但生成的 d.ts 尚未同步；仅以项目内交叉类型声明 manifest 中的公开签名，不修改框架或声明快照。
- `viewport.ts`：项目 HUD 策略，使用公开 setTransform 一次提交逆相机变换。原生文字和品牌 DOM 保留。
- `meteors.ts`：项目视觉生命周期，所有入口统一从内部目的点沿反向射线退出扩张视区，头/尾/光晕完整在外。尚未入场的对象保留名额；相机变化把未入场对象暴露时重新安置在外、重新淡入。已入场对象按完整几何回收。速度由有效屏幕尺寸唯一决定，淡出仍按原速度积分。
- 不新增模块，不访问私有框架。碰撞依旧真实扫掠、一次消耗；配对仅预测目的点，不强制碰撞。
